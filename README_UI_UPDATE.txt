LABEL LENS UI UPDATE

This build includes a high-contrast premium UI for both Dark and Light modes.
Use the Theme switch in the sidebar. All major cards, headings, controls, alerts,
tabs, tables, buttons, inputs and sidebar navigation use theme-aware colors.

Run:
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
